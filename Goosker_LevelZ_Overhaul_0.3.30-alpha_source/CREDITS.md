# Credits

## Excalibur icon textures
Selected icon textures in Goosker's LevelZ Overhaul are adapted from **Excalibur V1.20** and **Excalibur Epic Knights Compat** by **Maffhew**.

Maffhew granted Dalton / Goosker explicit permission on August 19, 2026 to re-use and adapt Excalibur textures for this LevelZ overhaul / Goosker's Medieval Modpack.

Current Excalibur-derived icon elements include the chainmail chestplate, leather boots, enchanted-book palette, longbow, arrow, emerald, and diamond pickaxe.

Vigor, Dexterity, and Husbandry use custom assets supplied by Goosker. The 2D Smithing anvil and the composite/open-book treatments were created specifically for this addon.
