This is a complete rework/overhaul of the Mod LevelZ. It aims to add to vanilla progression rather than slow it down, so typically all player stats will start at or close to what they already are in Vanilla minecraft, and they get better and better the higher you level up.

I've implemented magicka to level up multiple mods that contain magic items and increase their damage (from Deeper and Darker and Mebahal Creatures: Draugr Invasion)

I am super new to creating mods and don't know how to do most things, so if someone wants to build upon this project please go for it.
